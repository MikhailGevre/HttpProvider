Cервис-реестр HTTP-клиентов нескольких поставщиков.<br> 
У поставщика есть идентификатор, базовый URL и API-ключ.<br> 
Набор поставщиков можно заменить целиком.<br> 
По идентификатору поставщика и номеру телефона сервис узнаёт, доступен ли номер телефона.
<br>
## Логика работы
Запрос к поставщику: GET {baseUrl}/subscribers/{phone}.<br>
Ответ 200 с телом {"status":"ok"} означает, что номер доступен.<br> 
404 означает, что номер недоступен.<br>
Остальные HTTP-ошибки и сетевые ошибки доходят до вызывающего кода.<br>
Поставщики читаются списком по пути, который указан в application.properties
## Перед запуском приложения необходимо:
1. Cоздать application.properties <br>
2. Инициализировать переменные<br>
API_KEY_HEADER - Api ключ<br>
PATH_JSON_PROVIDER= Путь до Json файла с поставщиками<br>
### Возможные ошибки
EntityNotFoundException - запрашиваемого поставщика нет в Json.<br>
NoSuchFileException - путь не верный до Json файла.<br>
